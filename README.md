# 01 今天（周四）：证件和路，今天就落地
四川赛区的正式通知今天上午刚发布（11 月 26 日 9:30）。三件事今天就要确认。

**第一，考点在成都，全省只有两处**。具体考点和地址以准考证和赛区正式通知为准，不要按往年经验或群里的说法去猜。外市要跨市的孩子，今天就把车次、出发时间和返程定下来。考点不提供停车位，送考车辆即停即走，不建议自驾过去临场找位置。

**第二，准考证今天打印**。登录报名网站 cspsjtest.noi.cn 自行下载，只认纸质版。

**第三，证件核一遍，核的是号码，不是人**。证件必须与报名时注册的证件号码一致：注册身份证的，带身份证、临时身份证、带照片的社保卡，或派出所出具的带照片、带证件号、盖户籍章的证明；注册护照的，只能带护照。户口本这类没有照片的证明，一律不行。

四川的通知里有一句要单独划出来：**本次不提供“先进入考场、考完再补交证件”的方式**。缺一项，就是进不去。

# 02 明天（周五）：只做三件低强度的事
不建议再做新题，也不建议提前熬夜调作息——考前改作息，常常两头空。三件事就够。

**一，把 freopen 手写五遍**。四道题的 .in / .out 名字都在题面里，明天默写，写到不用想、不用回头看。

**二，用一个做过的题完整走一遍流程**：建文件、写 freopen、编译、过样例、存盘、交卷。目的是把动作练成肌肉记忆，不是练算法。

**三，把要带的东西装进一个袋子**：准考证、身份证、笔。草稿纸考场统一发，其余东西今晚就决定不带。

四川通知的禁带清单是：手机、耳机、手表、U 盘、移动硬盘、固态硬盘、键盘、鼠标、闹钟、计算器、书籍、草稿纸、背包。手机必须关机，并且把闹铃关掉——只按静音不算。

# 03 考场 270 分钟：按这张表走
时间表不是铁律，**它只防一件事：被某道题吸住**，一抬头已经十一点半。真正要守的只有三档——第一题必须拿满，第二题必须有分，最后 20 分钟必须留给检查。

**第三、四题的正确顺序是先写暴力**。四道题的满分都是 100 分，而一道没调的题和一个能过小数据的暴力，在分数上完全是两回事。写暴力的成本通常只有二十分钟，收益却是一档实实在在的分。

还有两条考场规定要记牢：开考 30 分钟后不得入场（按缺考处理），开考 30 分钟后才容许上厕所，结束前 30 分钟不准上厕所。所以进场前先去一趟，8:00 前后到场，别卡在 8:25。

# 04 七个白丢分的坑

这张表里的任何一条，都比多做对一道题更值钱。它们的共同点是：**不是不会，是会做却交出 0 分**。
